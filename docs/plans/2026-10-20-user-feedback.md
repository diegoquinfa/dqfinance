# User feedback

Feedback from real users, kept next to the plans so it can shape the Later list. Newest first.

## 2026-10-20 · Kriz911 (Discord)

What worked:

- The MCP with OAuth, and Grok Bot reading the inbox every night and recording expenses on its own. Entering
  expenses by hand is what kills any finance app.
- That the project is open source.

Requests:

1. **Budgets per category with early warnings.** Warn before the limit is crossed, for example "you are at 80% of
   food this month". Budgets are already on the Later list; this adds the threshold alert.
2. **Recurring subscription detection.** Find charges that repeat (same counterparty, similar amount, regular
   interval) that the user never registered as a recurring expense, and suggest adding them. Per D11 a
   suggestion never creates anything on its own.
3. **Month-end projection.** How much would be left at the end of the month if spending continues at the current
   pace, counting the recurring expenses still due.
